# Tasker

Tasker - небольшое веб-приложение для просмотра задач и добавления новых. Интерфейс позволяет быстро увидеть задачи по уровню приоритета и создать задачу с названием, описанием и приоритетом.

## Возможности

- Просмотр списка задач в виде карточек.
- Фильтрация списка по приоритету: все, низкий, средний или высокий.
- Создание задачи в модальном окне. Название обязательно; описание можно оставить пустым.

## Технологии

- React 19 и TypeScript.
- Vite для разработки и сборки.
- CSS Modules для стилей компонентов.
- React Context для общего состояния списка задач.
- TanStack Virtual - для виртуализации списка задач.
- Vitest - для тестирования.
- ESLint для проверки кода.

## Запуск

```bash
npm install
npm run dev
```

Другие команды:

```bash

```

## Архитектура

В проекте используется методология Feature-Sliced Design.

```text
src/
├── app/                    # корневой компонент и композиция приложения
├── pages/tasks/            # страница списка задач и состояние фильтра/модального окна
├── widgets/
│   ├── task-list/          # список задач и фильтрация отображаемых карточек
│   └── task-create-modal/  # модальное окно создания задачи
├── features/
│   ├── task-create/        # форма, валидация и создание задачи
│   └── task-filter/        # выбор приоритета для фильтра
├── entities/task/          # типы задачи, контекст, хук, мок-данные и карточка
└── shared/
    ├── ui/                 # переиспользуемые Button, Field, Modal и Select
    └── lib/                # генерация идентификаторов и утилиты классов
```

### Модель задачи

Задача (`Task`) содержит:

- `id` — идентификатор;
- `title` — название;
- `description` — необязательное описание;
- `priority` — `low`, `medium` или `high`;
- `createdAt` — время создания в миллисекундах.

### Решения по оптимизации

- **Ленивая загрузка формы.** `React.lazy` загружает компонент формы создания задачи при первом открытии модального окна, а `Suspense` показывает индикатор загрузки на время импорта. Это позволяет нам подгружать код формы только при необходимости.
- **Виртуализация списка.** TanStack Virtual отображает только видимые карточки задач + 5 задач. Это сокращает число элементов в DOM при длинном списке.
- **Мемоизация фильтрации.** `useMemo` сохраняет результат фильтрации и пересчитывает его, когда меняются задачи или выбранный фильтр.
- **Стабилизация контекста.** `useCallback` сохраняет ссылку на `addTask`, а `useMemo` — на объект контекста, пока не изменится список задач. Это предотвращает лишнюю смену ссылок при повторном рендере провайдера.
- **Измерение высоты карточек.** Виртуализатор измеряет фактическую высоту элементов, поэтому учитывает карточки разной высоты.
